# 日志与监控说明

## 日志原则
- 不记录完整卡号
- 不记录 CVV
- 不记录 Secret Key、Webhook Secret、API Token
- 仅记录允许保存的卡摘要，例如品牌、后四位、发卡国家
- 对失败信息做安全摘要，避免暴露风控规则细节

## 建议监控项目
- `/api/webhooks/stripe` 错误率
- `/api/support/checkout` 错误率
- 后台退款接口错误率
- 数据库连接失败
- WebhookEvent `FAILED` 数量
- 待确认交易数量异常增长
- 同一 `SupportSession` 出现多个成功付款的异常

## 告警建议
- 5 分钟内 Stripe Webhook 连续失败超过阈值时告警
- 付款成功率突然下降时告警
- 退款请求失败率上升时告警
- 法律资料缺失但尝试生产发布时告警

## 工具建议
- 错误监控：Sentry 或等效方案
- 应用日志：托管平台日志 + 聚合查询
- 可用性检查：定时探测首页、支持页、后台登录页、Stripe Webhook 路径

## 排查优先级
1. 支付创建失败
2. Webhook 验签失败
3. 数据库写入失败
4. 收据重复或未发送
5. 后台退款失败
